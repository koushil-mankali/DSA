# Trees

> Binary trees, BSTs and tries. You get the idea, a reusable JS template, and worked interview problems from easy to hard.

## Why Trees Matters

Interviewers pick problems from a small set of patterns. This section teaches the ones in **trees** so you can recognise them quickly and write the solution without panic.

Each chapter opens with a plain-language idea, shows how to spot the pattern, gives a template, and then walks through problems from brute force to optimal.

## How to Use This Section

1. Read the Big Idea and How to Spot It first.
2. Try each problem yourself for 15-20 minutes before reading the approaches.
3. Explain the optimal approach out loud without looking.
4. Re-type the template from memory the next day.
5. Do the Practice List problems on an online judge.

# Four-Week Revision Plan

> A schedule for someone who can already code and has about 1.5-2 hours a day. Adjust the pace, but keep the order: later weeks use earlier ones.

---

## How the Plan Works

- Each day: read one chapter's idea and template (30 min), then solve 2-4 problems from it (60-90 min).
- Try each problem for 20 minutes before reading the approaches. If stuck, read only the Intuition line, then try again.
- End every day by re-typing one template from memory.
- Every 7th day is revision: redo 5 problems you struggled with, with no notes.

# DSA Interview Handbook (JavaScript)

> From the smallest problem to the hardest. Plain-language explanations, reusable templates, tested JS solutions and a revision plan for coding interviews.

## How to Use This Guide

1. Follow the sections in order. Each chapter lists its prerequisites.
2. In every chapter, read the idea and how to spot the pattern, then attempt each problem before reading the approaches.
3. Solutions go brute force, better, optimal, so you can narrate the same path in an interview.
4. Use the [pattern cheatsheet](./07-interview-playbook/01-pattern-cheatsheet.md) for revision and the [four-week plan](./07-interview-playbook/03-four-week-plan.md) for scheduling.
5. Company tags are community-reported and unverified. See the [company index](./07-interview-playbook/02-company-index.md).
6. Look up any term in the [glossary](./glossary.md). Each section has a one-page SVG cheatsheet in this folder (`cheatsheet-NN-<section>.svg`).
